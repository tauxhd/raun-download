# Raun (prototype)

Ride-hailing for Papua New Guinea. This repo only hosts the Android test build.

## Install on Android

1. On your phone, open **https://tauxhd.github.io/raun-download/** (in Chrome). The download starts by itself.
2. Open the downloaded file. If Android asks, allow your browser to **install unknown apps**.
3. Tap **Install**, then open **Raun**.

## Try it

- Tap **Get started**, enter your name and a PNG mobile number (no SMS code in this prototype).
- To try the driver side, use a second phone, tap **Drive with Raun** and register a car.
  New drivers need approval from the Raun team before they can go online.

This is an early prototype: prices are estimates, payments are cash only (card is recorded, not charged), and data may be reset.
